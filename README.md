One pickup line (≤140 bytes), the worst an AI could plausibly say, written to
`entry.txt` for make.fun. `main.py` holds the line in `ENTRY` and writes it.

Run:

```
OUTPUT_DIR=/tmp/o python3 main.py
```

Prints `LEN=<n>` and exits non-zero if the line is empty or out of range.
